# Portfolio Web - Cristina Tornero

Portfolio personal desarrollado para presentar mi perfil como **Desarrolladora de Aplicaciones Multiplataforma**, mis habilidades, formación y proyectos.

## SOBRE EL PORTFOLIO

Este sitio web reúne información sobre mi perfil profesional y algunos de los proyectos que he desarrollado durante mi formación y aprendizaje.

El objetivo del proyecto es disponer de un espacio donde mostrar de forma visual mi evolución como desarrolladora y las tecnologías con las que he trabajado.

## 🛠️ Tecnologías utilizadas

- HTML5
- C#
- Unity
- JavaScript
- CSS3
- Git
- GitHub

## CONTENIDO

El portfolio incluye:

- Presentación y perfil profesional
- Habilidades y tecnologías
- Formación
- Proyectos realizados
- Demostraciones en vídeo de los proyectos
- Información de contacto
- Enlaces a GitHub y LinkedIn

## PROYECTOS DESTACADOS
